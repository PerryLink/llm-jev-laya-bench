# §7 结果 D——跨物种互补性：一个负结果

> **写法原则**：负结果的价值在于**它否证了什么**，而不是「我们没找到」。故本节先陈述被否证的架构主张，再给出**三个区制**的配对证据，最后说明**它能外推到哪、不能外推到哪**。

---

## 7.0 被否证的主张

**主张**：在长线任务中，用一个**廉价的、不同物种的**判定器做第一层，只在它不确定时升级到前沿模型，可以以更低代价获得**同等或更好的**判断质量。

**该主张依赖的唯一前提**：**异种判定器与 LLM 会在不同的条目上出错**（互补性）。若两者错在同一处，第一层就只是「更差的第二层」。

**在既有工作中，第一层多为 LLM 判 LLM**（[FrugalGPT](https://arxiv.org/abs/2305.05176)、[RouteLLM](https://arxiv.org/abs/2406.18665)、[AutoMix](https://arxiv.org/abs/2310.12963)、[Cascaded LMs](https://arxiv.org/abs/2506.11887)）。**但非生成式判别器并非没有先例**——RouteLLM 自身即评述 Hybrid-LLM 的 **BERT-based router** 与 Zooter 的 **BERT-style router**；故 **「异种是否意味着互补」的问题不是「此前无人用过异种第一层」，而是「此前无人把它当作受控第一层与前沿生成器做配对互补性检验」。**

**本节的答案：在测过的三个区制上，均未发现互补。**

---

## 7.1 度量

在**同一条目**上让两个判定器各答一次，做**配对比较**：

```
Δ_catch = P(类型化判定器正确 | LLM 错误) − P(类型化判定器正确 | LLM 正确)
```

- **配对**设计使条目难度**在条目内相消**，因此 Δ_catch **不受准确率水平差异的混淆**——这是所有「A 比 B 准」类比较无法避免的问题；
- 同时报告**混淆矩阵**（两者皆对 / 仅类型化对 / 仅 LLM 对 / 皆错）与 **Cohen's κ**；
- **判据以 Δ_catch 的符号为准**，不以「仅类型化对」的计数是否非零为准（见 §7.4 的一处修正）。

---

## 7.2 区制一：权威定位（模板匹配类）

**条目**：`DECOY + filler + CORRECTION`，多处陈述中需找出被标记为权威的那一条；**所有选项在数值上都合理**（避免「用合理性排除」这条捷径）。48 个配对条目。

| 指标 | 值 |
|---|---|
| **LLM 准确率** | **1.0000（48/48）** |
| **Laya 准确率** | **0.4583** |
| 仅 LLM 对 | **26** |
| **仅 Laya 对** | **0** |
| 两者皆对 | 22 |
| κ | **0.0** |

→ **LLM 一次都没错**，因此 `P(Laya 对 | LLM 错)` 与 **Δ_catch 均无定义**。
→ 能说的只有：**在这个区制上 Laya 未捕获任何 LLM 漏掉的条目（仅 Laya 对 0 / 仅 LLM 对 26）**，而是在 26 个条目上单独失败。

**此区制的证据强度**：**上限效应** —— 它**不能**证明「无互补」，只能证明**本电池无法测量互补性**。

## 7.3 区制二：77 类意图分类（Laya 的相对强项）

**为什么选这里**：P14 的负结果之后，我原本假设互补性应出现在 **Laya 的相对强项区制**。P7 曾测得第二层（≤3 候选，**条件于祖先正确**）达 **0.867**，故被选为「强项」。

**但那个假设本身是错的**：0.867 是**条件化产物**。真实部署里祖先不知道自己错，而**组选择只有 0.275，且错误是终局的**。

**设计（诚实的部署对比）**：同一批 40 条**真实 Banking77 测试集语句**——
- **Laya**：走完整层级（自选组 → 组内选意图），组选择错误即终局；
- **LLM**：一次面对**全部 77 个真实意图标签**（**更难的**任务）。

**⚠️ 本节已改为报告 4 次独立抽样**：记录那一轮未传 `temperature`，故 LLM 臂是 API 默认采样器的**单次抽样**。复核时以 `temperature=0` 重跑 **3 次**（同一批 40 条、同一 seed），连同记录轮共 **4 次**。

| 指标 | 记录轮 | 复现 r1 | 复现 r2 | 复现 r3 |
|---|---|---|---|---|
| **LLM 扁平 77 类** | 0.7500 | **0.9000** | 0.8750 | 0.8750 |
| **Laya 完整层级（端到端）** | **0.2250** | **0.2250** | **0.2250** | **0.2250** |
| Laya 组选择 | 0.2750 | 0.2750 | 0.2750 | 0.2750 |
| 仅 LLM 对 | 23 | **27** | 27 | 26 |
| **仅 Laya 对** | **2** | **0** | **1** | **0** |
| **Δ_catch** | **−0.033** | **−0.250** | **−0.029** | **−0.257** |
| Δ_catch 95% CI（**未配对 Wald；见下注**） | [−0.324, +0.257] | [−0.391, −0.109] | [−0.406, +0.349] | [−0.402, −0.112] |
| Δ_catch 95% CI（**Newcombe**，零格时可信） | [−0.260, +0.297] | [−0.411, +0.253] | [−0.259, +0.409] | [−0.421, +0.192] |

> **⚠️ 本行两格曾印错（第五轮复核发现并更正）。** 记录轮一格原印 **[−0.324, +0.257]**——那是**同列 Wald 值的逐位复制**，被误当作 Newcombe 值；r2 一格原印 **[−0.410, +0.184]**，**不是**该数据的任何 Newcombe 区间（穷举 `n₁≤14, n₂≤41` 的全部元组，唯一给出该区间的组合是 `(5,13,13,25)`，与本区制任何单元都不符）。两格现按 **Newcombe 法 10（Wilson score 的 MOVER）** 重算。r1 与 r3 两格经复算**原本即正确**。
> **这一更正是有利于结论方向的**：更正后**四次抽样的 Newcombe 区间全部包含 0**（原表只显式指出两次）。
> 全部区间与精确检验现由 `src\analysis\p28_recompute_all_stats.py` 统一重算，输出 `results\P28-recomputed-statistics.json`——此前这些数字**没有任何脚本**可复现（全树无 Wald/Newcombe/Fisher 代码），正是这一缺口让一个 Wald 值长期冒充 Newcombe 值。

**四条读数**：
1. **Laya 完全确定**：4 次抽样中端到端与组选择**逐位相同**（0.2250 / 0.2750）——Laya 无采样，条目集固定。
2. **记录轮的 0.7500 是 4 次中最低的一次**。复现值集中于 **0.875–0.900**（经验中心 ≈0.875，均值 0.850）。**故摘要不得再把 0.7500 当作 LLM 的能力值**，应写「0.750–0.900（4 次抽样），中心 ≈0.875」。
   → 这也**削弱**了污染论证的一个前提：LLM 若靠记忆，其真实水平更可能在 0.875 附近。
3. **Δ_catch 在 4 次抽样中全部 ≤ 0，从未为正**——其中记录轮（−0.033）是**对互补性假设最有利**的一次。**符号稳定，幅度不稳**（跨度 0.229）。
   **⚠️ 但「CI 排除 0」在本区制上是统计假象，不得引用**：4 次中有 2 次的「仅 Laya 对」计数**恰好为 0**（r1 为 0/4、r3 为 0/5），**零格使 Wald 区间丢掉该臂的全部方差**，区间被虚假收窄。改用 Newcombe 法后，**四次抽样的区间全部包含 0**：[−0.260, +0.297] / **[−0.411, +0.253]** / [−0.259, +0.409] / **[−0.421, +0.192]**——其中恰好是计数为 0 的 r1 与 r3，其 **Wald** 区间（[−0.391,−0.109]、[−0.402,−0.112]）**排除 0 而 Newcombe 不排除**，这就是假象的确切来源。0/4 的 **95% 单侧精确上界为 0.527**、0/5 为 **0.451**（`P28-recomputed-statistics.json`；早期版本印的 0.602 / 0.522 是 **97.5% 单侧**界，对应双侧 95%）。**⚠️ 但不能就此说「数据与高达 +0.35 的 Δ_catch 相容」**——该说法不是任何区间：**Newcombe 的上界为 +0.253（r1）与 +0.192（r3）**，这才是与数据相容的上限。
   ⇒ **本区制唯一稳健的陈述是「4/4 次符号为负」**，不是「2 次显著」。同 2×2 的 Fisher 精确 p = **0.557 / 1.000 / 0.570**（修复前的记录轮为 1.0000）——**没有一次接近显著**。
4. **「仅 Laya 对」在 3 次复现中为 0 / 1 / 0**（记录轮为 2），而「仅 LLM 对」为 26–27。**Laya 几乎从不捕获 LLM 漏掉的条目。**

→ **裁定**：**在 4 次独立抽样中，没有一次显示互补**；记录轮是最有利的一次，仍然是负的。故本区制的结论比原来**更强**：不再是「n=40 不显著所以无法判定」，而是「**方向在 4/4 次抽样中一致，且在最有利的一次仍为负**」。

## 7.4 我在本节修掉的一个判据缺陷

首次运行的脚本**宣布「COMPLEMENTARITY EXISTS」**，理由是「仅 Laya 对」非零（=2）。
**这是错的**：当时「仅 LLM 对」是 **23**，而 **Δ_catch 为负**。

**修正**：判据改为**以 Δ_catch 的符号为准**（阈值 +0.10 才算支持）。
→ **教训**：一个非零的「仅 A 对」计数**不构成互补性**，除非 A 同时在 B 失败处更可靠。**计数与符号是两件事。**

## 7.5 结论与外推边界

**结论**：
> 在测过的**三个**任务区制上，**异种判定器不提供增量覆盖**。其中一个区制上 LLM 严格占优（仅 LLM 对 26 / 仅判定器对 0）；另一个上 LLM 触顶使其错误结构**无法测量**；第三个区制上限被打破，**真值修复后重判**，Δ_catch 一致为负（3/3；未配对 Wald 下 2 次排除零，**⚠️ 但该区间收窄的原因与区制二不同：本区制的格子是 17/29/3/19，没有零格**——零格是**区制二**的情形，早期版本把那条解释误植于此。改用 Newcombe 后**仅 1 次稳健排除、1 次在边界**），且失败相关**在 3/3 次抽样中为正**——即证据**与「共享失效」一致**，而非互补。
> **⚠️ 强度限定**：该相关的 Fisher 精确 p = **0.086 / 0.049 / 0.163**（r1/r2/r3）。**未校正时仅 1/3 次在 α=0.05 下显著（r2，p=0.0487，距阈值仅 0.0013）；而按本文自己的 Holm 规则（§4）三次全部不存活**（首个阈值 0.0167）。「条件正确率 vs 边际」的单侧检验其 95% CI 在 **3/3** 次中包含 0。
> **MDE（0.28–0.30）仍大于预声明门（+0.10），故这是「方向 3/3 次一致、Wald 下 2 次排除零（Newcombe 下 1 次稳健、1 次在边界）」，不是精确的效应量。**
> **「廉价异种判定器做第一层」这一架构，在本项目测过的任务上得不到支持。**

**能外推到哪**：

| 可以 | 不可以 |
|---|---|
| 「异种 ≠ 自动互补」——**架构选择需要一个正面的互补性证据，不能靠物种差异假定** | **不能**说「任何情况下都无互补」 |
| 在**单文本、有明确标签、可单跳判定**的任务上，LLM 的准确性优势足以淹没异种第一层的任何收益 | **不能**外推到开放式任务、需多跳检索的任务、或标签空间极大且需外部知识的任务 |
| 在**任一判定器触顶**的电池上，互补性**不可测**（而非「不存在」） | **不能**把「不可测」当作「不存在」 |

**必须写入局限的**：本项目测了**三个区制**，其中**前两个都让 LLM 触顶或接近触顶**（因而**不可测量**），第三个上限已破除但**效力不足**（MDE = 0.311 远大于预声明阈值 +0.10）。**因此这是一个关于「如何判定架构主张」的方法论结果，不是一个关于「异种判定器无用」的普适结论。**

## 7.6 区制三：多跳链式核验（**上限已排除；真值修复后 Δ_catch 一致为负，失败相关同向**）

**为什么必须做第三个区制**：前两个区制都无法判定主张——因为**一方没有失败**。区制一里 LLM 48/48 全对，区制二里它 0.750–0.900 且差距被任务难度主导。**当一方不失败时，「两者是否失败在不同处」不可测量。**

**换条目无用**：现存条目全是「模板匹配 + 单跳核验」，与 LLM 的强项完全重合。**必须换结构。**

**CHAIN-AUDIT 的结构**：审计轨迹含 K 个操作行（`+d / −d / ×2 / ÷2`），其中一部分标记 **`SUPERSEDED — DO NOT APPLY`**；问题要求**最后一条未作废步骤之后的值**。真值由程序模拟给出。
**证书**：生成器计算 `simulate(忽略作废行)` 与真值，**不相等者才入池**（复用 §4.3 的机制）。
**⚠️ 措辞更正**：论文早期版本写「生成器**断言**……不满足者在构建期即被拒绝」，但代码是 `if alt == truth: continue` —— 一次**静默过滤**（96 → 68），**不是断言**；且实测 8/96 条链上 `simulate(ignore_superseded=True)` **并不等于**「把渲染出的每一行照读」（因为奇偶性调整已改变活动值），故 `alt` 是「忽略作废标记」的一个**近似**，不是字面读法。

→ **LLM 的失效结构（已按可答分母更正）**：在**真正提供了**「忽略 `SUPERSEDED`」这一选项的条目上，LLM 选中它的比率为 **11.5% / 13.1% / 13.1%**（7/61、8/61、8/61；记录轮 10/62 = 16.1%）。**该率按条件读才有意义**：在 LLM **答错的**条目里，**31.8–34.8%** 的错误**恰好就是**「把作废行也照做」（r1 7/22、r2 8/23、r3 8/23）；在 **K≥8** 的深链上为 **29.4–32.3%**（K=8 10/31、K=16 10/34）。

→ **Laya 一侧的证据强得多，且是本节对中心假说最直接的证据**：其该率（可答分母）为 **34.4%**，在**答错的**条目中占 **43.8%**；而在**最浅的 K=2** 上，它**有一半的条目（18/36）直接给出「把作废行也照做」的结果**，占其全部错误（21 条）中的 **85.7%**。
   ⇒ **在链式电池最简单的形态上，Laya 的主导行为就是「不作废、全部执行」**——深度还没成为问题时，它就已经不执行「跳过被作废行」这条指令了。这正是 §6.3「缺少检测缺席的通道」在**非推断**意义上的实例，也与 §7.6.2 的「能力缺位 vs 误差复合」相互印证。
   ⇒ 注意**两个方向相反**的读数必须并置：**Laya 犯「忽略作废」这一特定错误比 LLM 更频繁（34.4% vs 11.5–13.1%）**，而它的**总体**准确率也更低（0.294 vs 0.662–0.677）。

### 7.6.1 ⚠️ 本电池的真值缺陷与**修复后的重判**（本节结论已按修复版重写）

**缺陷**：`make_chain` 在 `div` 遇奇数时静默调整奇偶性，而 `simulate()`（源码自称 *"Authoritative truth"*）不重现它；且**文档化的证书从未实现**。后果：**11/69 条（15.9%）的判分真值不能由渲染出的题面推出**（其中 10 条的「忠实读法」答案甚至不在选项中）。

**修复**：奇偶性调整现按步记录，`simulate()` 在 **superseded 判定之前**重放它（生成器在**求值**一步时就已改写活动值，即使该步之后被作废），证书**已实装为断言**。修复后 **96 条生成 → 0 条不可推导 → 68 条入池**。

### 7.6.2 附带结果：两种根本不同的失效模式

**⚠️ 形状必须更正（第五轮）：不是「随深度单调崩塌」，而是「在 K=4→8 之间跌落一次，此后完全平坦」。**
逐 K 复算（三次固定抽样合并，LLM 判定数 / 该 K 的总判定数）：

| K | LLM 准确率（3 次合并） | Laya | 相邻对比的 Fisher 精确 p |
|---|---|---|---|
| 2 | 33/36 = **0.917** | 0.417 | — |
| 4 | 36/36 = **1.000** | 0.250 | K=2 vs K=4：**p = 0.239**（不显著，且方向是**上升**） |
| 8 | 32/63 = **0.508** | 0.286 | K=4 vs K=8：**p = 3.6×10⁻⁸** |
| 16 | 35/69 = **0.507** | 0.261 | K=8 vs K=16：**p = 1.000**（**完全平坦**） |

⇒ 浅层（K∈{2,4}）与深层（K∈{8,16}）的合并对比：**23/24 = 0.958 vs 45/88 = 0.511，Fisher p = 1.4×10⁻⁴（3/3 次抽样均在 10⁻⁴ 量级）**。
⇒ 故**「崩塌」只发生在一次跨越上**：K≤4 时接近上限，K≥8 时降到约一半并**不再随深度变差**。
⇒ **原文「随深度崩塌」「K=2 → K=16，0.917 → 0.478」只描述了 r1 这一条抽样**；r2/r3 在 K=8→K=16 上是**上升**的（0.476 → 0.522），三次抽样**没有一次**是单调的（K=2→K=4 在 **3/3** 次中都是上升）。
⇒ **机制尚未确定**：深层错误**不是**「算错一步并累积」——若是复合误差，K=16 应显著差于 K=8，而实测差为零。**逐条看，LLM 在 K≥8 的错误几乎全部落在真值邻域的近似诱饵上**（而非「恰好等于忽略作废后的值」，后者在 K≥8 只占 16.7% / 其错误的 29–32%，见 §7.6）。更可能的解释是**在某个深度上从「执行」切换到「在近邻候选中择一」**；本电池**没有**区分这两种机制的设计，故此处只记现象，不作机制断言。

| | LLM | Laya |
|---|---|---|
| K=2 → K=16（修复前电池） | 0.833 → **0.417** | 0.417 → 0.250 |
| K=2 → K=16（修复版三次） | 0.917 → **0.507**（K=4 时 1.000） | 0.417 → 0.261 |
| **形状** | **一次跌落（K=4→8）后平坦** | **平坦，恒在随机附近** |

→ **Laya 在 K=2（本电池最简单形态）时就只有 0.417，且随深度不再变化** → **它不是「随深度退化」，而是根本没有在执行链式计算。**
→ 这与 §6.3 一致：它**在「需要注意到某物缺席」的任务上塌缩**，而本电池**每一行都要求它注意 `SUPERSEDED` 标记**。

| 判定器 | 失效方式 | 是否随负载恶化 |
|---|---|---|
| **LLM** | **一次跌落**：K=4→K=8 之间下降，此后平坦（**非误差复合**——K=8 与 K=16 的 p = 1.000，机制未定，见 §7.6.2） | ⚠️ **否** |
| **Laya** | **能力缺位**：恒定在随机附近 | ❌ 否 |

→ **对「长线任务」的含义**：**用恒定失效的组件去兜底累积失效的组件，在原理上不可能奏效** —— 这正是 Δ_catch 为负的结构性背景（**⚠️ 第八轮更正：原印「Δ_catch ≈ 0」是修复前的 −0.007；修复版三次为 −0.182…−0.247**）。

## 7.7 截断的证据（P24 + P26）

§5.3.1–5.3.2 报告了累积运行中的窗口侵蚀与截断伤害。此处只记其对**本节主张**的意义。

**可作为证据的部分是「截断会发生」**：P24 显示 60 步里只有 14 步能塞进窗口、末态 3.4× 钳位；P26 的 20 次调用全部录得 `in_pad = 512`、`truncated = true`。

**⚠️ 但 P26 原设计不足以证明「截断改变了答案」**（详见 §5.3.2），有两处缺陷：
(a) **两臂的可见前缀逐位相同**——dropped 臂仍有 ~4× 钳位，更正位于第 1,943–1,952 个 token，**超出两者共同的 512 窗口**，故「两臂同答」是**构造的必然**；
(b) 选项顺序与答案共线（诱饵恒首位、真值恒末位），而 Laya 10/10 选首位。
**复核时补做了缺失的对照**：**⚠️ 该定量断言已撤回（第七轮）**：那组数字（6/10、4/10、p = 0.011、状态 79–92 token）**在整棵树中没有任何产物**，且其状态规模恰等于 P26 **已废弃首版原型**的规模。**撤回**；本节只保留「截断会发生」这一有产物支撑的部分。

→ 因此本节的「统一形态」有**两个有产物支撑的实例，第三个的支持不足**：截断那一格**只能证到「截断会发生」**——早期版本印的「解释其中约 6/10、另 4/10 发生在证据完全可见时」**所依据的对照臂无产物，已撤回（第八轮）**。

| 任务 | 需要「注意到」什么 | Laya | LLM |
|---|---|---|---|
| 链式核验（K=2…16） | 某行被标记作废 | **0.25–0.42（恒定）** | **0.917 → 1.000 → 0.508 → 0.507**（修复版三次合并；K≥8 后平坦，**非单调**）|
| `no_support` 档（n=220） | 候选值**根本没出现过** | **acc 0.3091，平均 P(true)=0.5643** | ~1.00 |
| 超窗状态（对照臂，n=10） | 更正**完全可见**却未被采纳 | **⚠️ 该对照无产物，数字已撤回** | — |

→ **前两者都不是「算力不足」，而是「缺少检测缺席的通道」。**
→ **第三者性质不同，必须分开说**：（该拆分已撤回：所依据的对照臂无产物），属「看见却不采纳」，**不是**检测缺席。故「缺少检测缺席的通道」**不能**涵盖它。

## 7.8 尚未执行的实验：跨会话累积的**自主**运行

**本节的 horizon 证据是缩减版**：P24 的 3×20 步累积**在同一进程内**、**无工具使用**、**无跨进程恢复**，且判定器被当作**判断器**调用，而非自主智能体。
→ **它测的是「累积状态是否侵蚀窗口、以及截断是否改变答案」，而不是「自主长线运行的可靠性」。**
→ **论文不得把它升级为后者。** 见 §10.1 第 1 项。

## 7.9 限制

1. **区制一存在上限效应**（LLM 48/48），故其证据**不能证明无互补**；
2. **区制二 n=40**，一项动 0.025；**Δ_catch 的幅度在 4 次抽样间从 −0.029 变到 −0.257** ⇒ 能说的是**「4/4 次方向为负、记录轮是最有利的一次」**，不能说「效应量是 −0.033」；
3. **污染**：Banking77 是 Laya 的**先前集合**，而 **LLM 侧的暴露更直接**——`D3` 自己记录该模型在 45T token 上训练且含 Common Crawl，并写明「the LLM may have memorised the labels」。
   **⚠️ 因此「污染是保守的」这一论证只覆盖一侧，必须更正**：Banking77 的测试语句与 77 个标签名都是公开纯文本，LLM 的 0.75 若无记忆很难达到；而 **Δ_catch 为负正是由「仅 LLM 对 23 条」撑出来的**——**LLM 侧污染与本文的负结论同向，不是保守方向**。
   ⇒ 本区制的负结果因此**更强**（污染若抬高 LLM，只会让互补性更难看），但**「异种无用」的普适外推不能建立在这个区制上**。真正干净的区制是**区制三**（真值由程序模拟生成，不来自任何公开语料）。
4. **Laya 的层级用程序化分组**（按标签名 token 相似度凝聚），**顶层分组质量本身是瓶颈**（组选择 0.275）。**换一个语义更好的分组可能改善端到端**，本轮未测 —— 这是本节最重要的未排除解释；
5. **LLM 只测了一个配置**（`deepseek-flash`、非思考、单次采样）。
