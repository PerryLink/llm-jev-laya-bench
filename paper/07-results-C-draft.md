# §6 结果 C——能力塌缩：判定器在「必须注意到缺席」时失效

> 本节是论文的**组织核心**：它把 §3（仪器自报不可信）与 §5（窗口/延迟）之外的散落发现，收束成**一条统一形态**。

---

## 6.0 统一形态

> **同一个判定器，在「答案被明确陈述」的任务上近乎完美（`explicit_support` 0.9909，n=220），在「必须注意到某物缺席或某处不匹配」的任务上塌缩（`explicit_contra` 0.2727 / `no_support` 0.3091 / `partial_contra` 0.5818 / `partial_support` 0.6818，各 n=220）；而在两种情形下，它自报的置信度都不低。**

这条形态由**三个独立实例**支撑，分别对应三种「缺席」：

| 实例 | 缺席的是什么 | 证据 |
|---|---|---|
| **静默截断** | 输入的一部分（被丢弃而仪器说「通过」） | §3.2–3.3 |
| **`no_support`** | 证据（候选值根本没出现） | §6.3，n=220 |
| **跨语言** | 语言匹配（读的不是英文） | §6.4，n 小 |

## 6.2 `confidence` 与正确性的关系（n=1100）

**主结果**（P19，1100 条二值项，真值由构造计算，两判定器配对运行）：

| | Laya | LLM |
|---|---|---|
| 准确率 | 0.5673 | 1.0000 |
| **ECE** | **0.2259** | 0.0028 |
| **Brier** | **0.2571** | 0.0000 |
| 常数预测器 Brier（基率 0.4） | **0.240** | 0.240 |
| **优于常数预测器？** | ❌ **更差** | ✅ |

→ **Laya 的 Brier 高于「永远按基率预测」** ⇒ 它的概率**比常数预测器更差**。
→ **但这不是「没有信息」。** 对同一批 1100 条做 **Murphy 分解**（10 等频箱）：**REL = 0.0556 / RES = 0.0397 / UNC = 0.2400**；且 **AUC(`noul`; truth) = 0.7136，95% CI [0.682, 0.745]**（n_pos=440 / n_neg=660）。
→ **分辨力真实存在（AUC ≈ 0.71），失效在「校准」而不在「信息」。** 故正确表述是**校准差**，**不是**「负信息量」——本节早期版本用过后一措辞，已更正。
→ **但它的 ECE 并不显得灾难性**，因为两侧误差相互抵消 → **协议条款：校准必须同时报 Brier、常数基线与 AUC 三者**。

**可靠性曲线形状**（Laya，**10 个等宽箱、[0,1]、末箱右闭**，**全部 10 箱都有质量**——最小 n=1）：**过度自信集中在中间，低端则相反**。

## 6.3 实例一：`no_support` —— 把「没有陈述」读成支持（n=220）

**设计意图**：该档位的**唯一目的**，是检验 R12 写进协议的那条规则——
> 「某物只有在 STATE 真的说了它时才被支持。**没有陈述不构成对它的证据。**」

| 判定器 | 准确率 | **平均声称 P(true)** | 真值 |
|---|---|---|---|
| **Laya** | **0.3091** | **0.5643** | 全部 FALSE |
| LLM | **1.0000** | 0.0012 | 全部 FALSE |

→ **面对「候选值根本没出现」的条目，Laya 平均给出 P(true) = 0.564，即倾向断言该值就是当前值。**

**另一处严重不对称**（同 n=220 各档）：

| 难度档 | 准确率 | 平均声称 P(true) |
|---|---|---|
| `explicit_support` | **0.9909** | 0.7811 |
| `partial_support` | 0.6818 | 0.5881 |
| `partial_contra` | 0.5818 | 0.4922 |
| **`explicit_contra`** | **0.2727** | **0.6070** |
| **`no_support`** | **0.3091** | **0.5643** |

→ **`explicit_contra`（0.273）比 `partial_contra`（0.582）更差。** 当 state **明确声明另一个值才是当前值**时，它**更容易**把候选值判成当前值。
→ **它在找「候选值出现过」，而不是「它是当前值」。**
→ **这解释了本项目早期简单条目上 Laya 拿 1.00 的原因**：那正是它唯一擅长的形态。

## 6.4 实例二：跨语言 —— 读的不是英文，却照样肯定（n 小，定性）

**前提更正**：本项**不是**路由测量。探针证明 **HTTP sidecar 从不路由**——对每种输入（含西里尔与天城文）都报告 `routing.reason = "explicit model selection"`，**不传 `--model` 亦然**。

| 文字系统分组 | n | 准确率 | 真条目平均 P(true) | **假条目平均 P(true)** |
|---|---|---|---|---|
| **英文原生** | 2 | 1.000 | 0.975 | **0.407**（正确否定）|
| 其他拉丁文字 | 12 | 0.500 | 0.917 | **0.747** |
| 非拉丁文字 | 2 | 0.500 | 0.968 | **0.4795** |

→ **英文上完美区分真假；一旦文本不是英文，就不再区分，而是倾向肯定主张**，且**假条目的 P(true) 高达 0.4795**。（**⚠️ 第八轮更正：0.912 是【评分标准写错】时测得的**——同一产物的真条目臂（标准两版都正确）在 8 种语言上 48/48 字段逐位复现，而假条目臂（已发布版标准写错了值）有 22 个字段不同。**修正标准后重测为 0.4795**（非拉丁语系假条目平均 P(true)）。0.912 确实被测量过，但它测的是「被问了畸形问题的判定器」，不是「没能注意到缺席的判定器」，故以 0.4795 为准。**定性发现在此基础上仍然成立**——0.4795 依然远高于校准良好的判定器在无支持条目上的表现。）

**限制**：英文与俄语各仅 2 条 → **只有定性形态可报告，不作逐语言主张**。

## 6.5 三个实例为何是同一件事

| 实例 | 要「注意到」什么 | 未注意到的后果 | 自报字段怎么说 |
|---|---|---|---|
| 静默截断 | 输入被丢弃了 | 答案翻错 | `fits: true`、无 `truncated`、无 warning |
| `no_support` | 证据不存在 | 断言为真（P=0.564）| `band` 给出低置信度，但 `noul` 高于 0.5（**⚠️ 不可核验：`P19-calibration.json` 没有 `band` 列，见下**）|
| 跨语言 | 语言不匹配 | 一律肯定（P=0.4795）| 置信度不低 |

→ **三者共用一个机制假说：该判定器的判断依赖「在文本中匹配到某个模式」，而不是「确认该模式的存在性或其权威性」。**
→ **当模式出现，它就对；当模式**应当缺席**或**不该匹配**，它没有对应的检测通道，于是退化为肯定。**

**【不可核验 ⚠️ ERRATA §10.2】**：上表 `no_support` 行的 `band` 断言**没有产物支撑**——`P19-calibration.json` 的 1100 行里**没有 `band` 字段**（`band` 是接入层推导量，P19 记录的是 `noul` 与 `laya_p`）。本行因此**只作为形态描述保留**：有产物支撑的是 `noul` 的分布（平均 0.5643）与准确率（0.3091），**不是** `band` 的取值分布。**若要主张 band 的分布，需要重跑并记录该字段**（未做）。

**这个假说可被证伪**：若在「候选值不出现」的条目上给它一个**显式的缺席标记**（如 state 里写明「本项无记录」），而它仍答「真」，则假说成立；若它随即答对，则问题在于**没有告知**而非**无法察觉**。
→ **这是一个尚未执行的、便宜且决定性的实验**，列为下一步 ⬜。

17. **凡判定臂经 API 采样，必须显式固定 `temperature`，并报告重复抽样之间的逐项标签一致率。** 依据：本项目记录轮未传 `temperature`，导致链式区制的点估计在重跑间移动 0.07（总体）、0.20（κ）、0.20（Δ_catch），逐项标签一致率 **58.8–63.2%**（三次配对分别为 40/68、43/68、41/68）；剔除 7 条选项集有变的条目后为 **60.7–63.9%**，见 §8.6.1。**⚠️ 早期版本只印三次中最低的那一次（58.8% / 60.7%），把一个范围写成了单值**；固定后升至 **86.8–89.7%**。**判定器（非生成）臂应达 100%**——该臂在**选项集未变的条目上正好是 61/61 = 100%（3/3 次）**，其与记录轮的唯一分歧恰落在一条选项集改变了的条目上，故它是 (state, options) 的确定性函数，达不到即说明该臂并不可复现。

## 6.7 限制

1. **语料模板化**（5 模板 × 常量池）：**绝对准确率不是能力估计**；可用的是**难度间相对差异与校准形状**；
2. **LLM 触顶**（1.0000/1100）→ 本语料对 LLM **无区分度**，故**不能据此宣称「LLM 普遍优于 Laya」**；
3. **跨语言项 n 极小**（2/12/2），仅定性；
4. **每判定器每条目一次采样**；类型化判定器确定性（R13 实测逐位相同），LLM 为默认温度非思考模式；
5. **未测**：显式缺席标记实验（§6.5）、多跳链式核验（更难的电池设计）、`typed-decisions` 与 `multilingual` checkpoint 的同类曲线。
