## D1 — 是否启用 live Jev：**裁定「现在演练、把出境决定推后」**

**单元建议**：REHEARSE ON MOCK NOW AND DEFER（`decisions\D1-jev-live-decision.md`）
**我的裁定**：**采纳**，并附一条更正（见下）。

### 核心重构（这是 D1 最有价值的一点）

> **「启用 live」与「上传语料」是两个决定。**
> `provider: live` 是一行，撤销也是一行；**但出境不是。**

→ **先取可逆的一半**：登记凭据 + 在 **R12 附录 A 已公开的夹具状态**上跑判别器 A/B（**2 次调用、约 $0.0003、零新增出境**），把**不可逆的一半门控在一个尚不存在的语料上**。

### 三条支撑理由（我复核后同意）

1. **两条中心主张都不需要 Jev。**「成本不是约束」由价目表推出，任何电池结果都不能证伪它。**且反向论证更强**：Jev 的价格落在一条**既不报成本、也未确认 token 数**的路线上 → 加一个 Jev 行是**给论文赖以立足的成本表添一个不可核实的数字**。
2. **主张 (ii) 由本地证据独自承担**：Laya 的 **111 字符未告警截断窗口**，**多语窗口为 0 构成天然的内置阴性对照**；加 confidence 解耦、mock 的 Brier 0.359。
3. **更大的 state 上限不构成理由**：16,000 字符在实测密度下约 **3,712 token**（英文散文 4.31 chars/token）至 **6,667 token**（JSON 2.40 chars/token），而设计状态范围 **300–1,500 token** → **该窗口在设计上从不触发。**（⚠️ 2026-09-23 更正：原据 R13 印 **「÷ 6.33 ≈ 2,530 token」**。该常数是**截断扫描的合成状态**（同一句 filler 重复 45 遍）的密度，**不是英文散文**；散文实测 4.31。**理由的结论不变，且更正后更强** —— 但**该常数曾被用于本条论证，故一并记录**。见 `results/ERRATA.md` §12。）

### ⚠️ 我的更正：D1 的「可替代」论证**已被实测推翻**（但建议不变，且更强）

D1 声称「`laya_rank` 镜像了 Jev 的 `rank` 入口」，据此认为 Jev 两个「独有」原语都有本地对应物。

**第一步核查（我做的）**：本地包与 jevcore README 中均无 `laya_rank`。
- `laya_mcp` 的 `/version` 只报 `["noul","choice","score"]` —— **无 rank 原语**；
- `worker.py:759` 的 "ranking" 是**单调性保序**的注释，不是 API。

**第二步实测（开工前实测项 #1，已完成）**：`probes\P1-rank-vs-choice-report.md`，18 次调用，
→ **高基数 `choice` 也无法复现 `rank` 语义**：
- 准确率：**N≤10 可用（0.67–1.00）→ N=15 起崩塌（0.33）→ N≥20 完全失效（0.00）**；
- **AUC 从 1.00 衰减到 0.375–0.475（≈随机）** → **排序信息本身丢失**，不只是 argmax 变差；
- **18 次中 4 次正确选项获得精确 `p = 0.0000`，同时 confidence 高达 1.0000。**

→ **裁定：`rank` 是真实独立的能力。D1 的「可替代」论证作废。**

**但建议方向不变，且理由加强。** D1 的建议不依赖「可替代」：两条中心主张都不需要 Jev（独立成立）；Jev 的价格路线不报成本、会污染成本表（独立成立）；16,000 字符上限在设计范围内从不触发（独立成立）。
→ **原语不可替代，提升的是「保留 Jev 选项」的价值** —— 即 **「先取可逆的一半（$0.0003）」比原先更值得做**，而不是更不值得。

**该实测还独立产出论文的一条新结果**（P1 报告 §3.3）：**高基数下 confidence 反向指示正确性**——比截断发现更锐利，因为**截断丢掉的是输入，这里丢掉的是正确性本身，而仪器同时报告了最高置信度**。建议并入 Results B。

**对分片方案的直接影响**：MASSIVE（60 意图）与 CLINC150（150 意图）**若单层使用会落在完全失效区**。
→ 「粗到细两级」方案**第一级本身就在失效区**；可行替代是**每级 ≤10 选项的多层选择**，但**层间误差如何复合必须实测**（已列为新的开工前实测项 #6）。

### 冻结的门与期限

| 项 | 值 |
|---|---|
| **触发条件** | 凭据登记进 **DSH 凭据服务**（**shell export 无效**——DSH 会静默剥除）**且** 判别器 A（`noul ≥ 0.9`）与 B（边界差值非零）在**已公开夹具**上通过 |
| **成本** | 2 次调用，**约 $0.0003**，**零新增出境** |

| **降级期限** | **2026-10-13 仍无凭据 → 执行预写的降级方案**（改题、删 A2 与 A4-Jev），停止投入 |

## D2 — horizon 主张的范围：**裁定 N = 600（折中）**

**单元建议**：INTERMEDIATE at N = 600（`decisions\D2-horizon-scope-decision.md`）
**我的裁定**：**采纳**，及全部四条配套动作。

### 为何不是 1,910（三处独立缺陷）

1. **为未预注册的目标定价**：R14 自己预注册的是 0.04–0.05/倍增 = **28–35 点**，而 **300 条已有功效**（V2 与 V4 独立同结论）。
2. **假设 100% horizon-live，实际仅 43%** → 10 点的真实价格是 **~4,600 条**。
3. **为被混淆的估计量定价**：`d = H−4` 完全共线，**N 不修复共线设计**。

### 为何不降级

降级的代价仅为**一个 Results 子节的 p 值列 + 两句讨论**。标题、摘要四条主张、修正后的主终点 `P_detect(τ*)`、**四条证据腿中的三条**全部不动。
**「静默退化」论点在仅靠「仪器诚实性 + 截断」时即成立**，只需一条免费连接事实——从**已付过钱的运行**里取 `token_ratio(t)`。

| 目标 | 修正后成本 |
|---|---|
| 10 点分歧（含 57% 惰性条目） | **~4,600 条** |
| 10 点分歧（已识别 `L`/`L+C` 估计量，ψ_eff 0.40） | **~2,900 条** |
| → **修复买的是可识别性，不是功效** | |

### 冻结的设计参数

- **N = 600** = 120 槽位（**每族 30，4 族——F3 恢复**）× 5 层
- **每条目跑 `L` 与 `L+C`**（= 1,200 状态/判定器）+ **`H4-refreshed` +120**
- **120 个冻结 slot-run**；5 判定器**配对**
- **已认证 live ≥ 0.85**（当前 0.43 → 靠**必要性证书**提到 ~0.90）
- **预注册 MDE = 22 点**，**印在图上 + 写进摘要**（不是局限性章节）
- **升级**：仅当试点 ψ_eff ≤ 0.35 **且** live ≥ 0.85 → 升 **1,200**；**硬上限 1,200**
- 成本：机器 **3–4 h**；工期 **+2–3 周**（合计 7–11 周）

### 删除项

❌ survives-only 主分析 ❌ +375 逃生舱 ❌ 「纯描述性」方案

### 最高回报的单一动作（不是 N）

> **把已认证 live 从 0.43 提到 ~0.90 ⇒ 白得约 1,100 条（2.1× 有效 N）——靠重新设计，不靠扩规模。**

### 审稿人测试

描述性曲线**会被接受**，条件：置于**补充材料**、**MDE 印在图上**、**摘要声明 MDE**、且 **`d = H−4` 混淆被披露**。

### 污染立场（D3 的核心贡献，比数据集清单更重要）

**但污染是对称的**：`laya-family/_upstream-src/lang.py` 记录了 MASSIVE 的数字；`R2` 记录了 Laya 已发表的 AG News 0.910 / DAIR 0.480 / Banking77 0.425。

→ **立场：公共集仅作次级/描述性证据；头条结论来自构造式条目。**
→ **严密的三类**：程序计算标签（A2）、后采集采样 + 机械规则（A1）、自撰电池（A3）。

**一个漂亮的可运行探针**：**VitaminC 每一行都带 BIG-bench canary 字符串** → 可直接作为污染探针运行。

### ⚠️ 我的更正一：高基数问题在 D3 内部未一致处理

D3 正确处理了 **Banking77（77 类）**，但**对 MASSIVE（60 意图）与 CLINC150（150 意图）没有提示需要分片**。

**这是真实约束**（R13 实测）：
- Laya 的 `choice` 在 **>15–20 选项**处崩塌（20 选项实测给出错答，confidence 0.9981）；
- 选项文本在 **Path A 11 选项 / Path B 4 选项**起被压缩。

→ **MASSIVE 与 CLINC150 的意图分类若直接用 `choice`，会落在已实测的崩塌区。**
→ **必须在开工前设计分片方案**（粗到细两级选择，或分组后合并），**且分片会改变原语语义与真值映射**，须单独记录。
→ **不得**把这两个集合的原始准确率当作 Laya 能力上限。

### ⚠️ 我的更正二：`rank` 是最弱原语

**NFCorpus qrels 只有 673 个查询** → `rank` 的证据基数远低于其他原语。
→ 若论文要主张排序能力，**673 不够**；否则应**明确声明 `rank` 只作探索性报告**，不进入主分析。
