## 2. P26 的设计：证书被真正执行

**P25 的教训**：题目必须**不能从题面自身回答**。P26 采用 **P3 用过且有效的构造**——决定性内容是**一段叙述性更正**，问题**只问结论**，**题面既不含 v0 也不含 v1**。

**状态形状**（宽度固定，只有更正的位置在变）：
```
Ledger, oldest first.
[r1] opening statement: <label> = v0 <unit>
[r2] note: ...  [r3] audit note: ...
<90 行填充>
[c1] Correction: the authoritative <label> is v1 <unit>.   <-- 位于尾部
[r4] sign-off: review closed
```
→ **尾部截断的读者会丢掉 `[c1]`**，于是唯一支持就是 `[r1]` 的 v0。

**证书（构建期强制执行，10/10 通过）**：
- **必要性**：`v1 ≠ v0`；
- **`v1` 只出现在一条行内**（不在别处泄漏）；
- **题面既不含 v0 也不含 v1**（不会自我回答）。

**两臂**：
- **full**：更正**存在**，状态 **超窗**（1,969–1,982 vs 512）；
- **dropped（删除对照）**：**把更正从状态里删掉**，问同一个问题。

## 3. 结果

| 单元 | n | 正确 | 准确率 | **选中「更正前」值** |
|---|---|---|---|---|
| **full — Laya** | 10 | **0** | **0.000** | **10 / 10** |
| dropped（对照）— Laya | 10 | 0 | 0.000 | **10 / 10** |
| **full — LLM** | 10 | **10** | **1.000** | — |
| dropped — LLM | 10 | 0 | 0.000 | — |

**读法（这是关键，且与直觉相反）**：

- **dropped 臂的答案是「更正前」值，这是按构造成立的**——该臂里 `[c1]` 不存在，故 v0 是唯一有依据的值，**答 v0 在那里是「正确行为」，但在真值键上是错的**（真值键是 v1）。
- **因此诊断量不是「full 比 dropped 好」，而是「full 能否把两个状态区分开」**：

| 判定器 | full 臂答了 v1？ | dropped 臂答了 v0？ | 判定 |
|---|---|---|---|
| **Laya** | ❌ **否（0/10，全答 v0）** | ✅ 是（10/10） | **完全无法区分两个状态** |
| **LLM** | ✅ **是（10/10）** | ✅ 是（10/10） | **正确区分** |

→ **Laya 在两臂上给出逐项相同的答案（10/10 都答 v0）**，即**它的输出与「状态里有没有那段更正」无关**。
→ **这正是尾部被截断的特征**：`[c1]` 位于尾部，被丢掉，于是它只看到 `[r1]` 的 v0。
→ **而在同一批状态上，LLM 拿到 1.000（full）与 0.000（dropped）**，说明**它正常读到了更正**。

**裁定**：
> **截断伤害被测量到**：在 1,969–1,982 token 的状态上，本地判定器**无法区分含更正与不含更正的状态**，其答案在两种情形下**逐项相同**；而 LLM 在同一批状态上完全区分。

## 4. 我在本轮修掉的两个错误

**错误一（承重）**：首版状态只有 **79–92 token**，**远低于 512 钳位** → **根本没有可截断的东西**。
→ 该版**验证了探针却没测试现象**，却打印出「NO TRUNCATION HARM」这样一个**看似有效**的结论。修正为 90 行填充后状态达 1,969–1,982 token。

**错误二（承重）**：我的判据写成「full 准确率 < dropped 准确率 → 有害」。
→ **两臂都为 0.000**，于是判据打印「NO HARM」——**而两臂为 0 的原因恰好相反**：full 臂是**因为看不见更正而错**，dropped 臂是**因为没有更正而「错」**。
→ 修正为**直接问「full 臂是否答出了 v1」**（即是否读到了更正），并同时报告「选中更正前值的计数」。

**这两个错误都是「自身缺陷伪装成关于对象的结果」，且都由我预先设置的对照/计数暴露**——本项目第七、第八次同类错误。

## 6. 限制

1. **n=10 每臂**，方向明确（10/10 vs 0/10、LLM 10/10），但**未做剂量-反应**（不同超窗倍数）；
2. **单一状态形状**：更正在尾部，填充在中间。**若更正位于前部，结论应相反**——本电池只验证了「证据在尾部」这一情形，而**固定序列化器正是把最新内容放在前部**，故此情形对应「需要最旧证据」的任务；
3. **未测**：多语 checkpoint、`--truncate-left`（保留尾部）下的对照 —— **后者是一个现成的反向干预**，值得作为下一步；
4. 状态为合成填充文本，非真实长文档。
