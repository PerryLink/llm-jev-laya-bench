## 1. 两版结果并排（这就是本次最重要的产出）

| 指标 | **v1：描述性标签名** | **v2：不透明键（i01…i22 / g1…g6）** |
|---|---|---|
| coarse 准确率（6 组） | 0.762 | 0.762 |
| **fine 在 coarse 正确条件下** | **1.000** | **0.857** |
| **端到端准确率** | 0.762 | **0.667** |
| **扁平（21–22 选项）** | **0.905** | **0.333** |
| **端到端 − 扁平** | **−0.143**（分层更差） | **+0.333**（分层好一倍） |
| 判定 | ❌ 分层不可行 | ✅ **分层可行** |

**结论完全反转。** 唯一的变化是 **criteria 的键名**：v1 用意图名（`refund_request`、`battery_drain`…），v2 用 `i01`…`i22`。
**选项描述（criteria 的 value）在两版中逐字节相同。**

## 2. v1 的混淆变量（我自己造成的，已定位）

v1 里：
- **扁平臂的 criteria 键**是意图名，且**coarse 组的描述文字里逐字列出了这些意图名** → 扁平臂因此获得一个**免费的归组线索**（看到 `refund_request` 就知道属 money 组）；
- v2 里两侧都改成不透明键，且 coarse 描述改为语义化描述（**不再列举成员名**）→ **线索消失**。

**后果**：
- **扁平臂从 0.905 崩到 0.333** —— 与 P1 在 N=21 实测的 0.00 完全同向；
- **fine 层从 1.000 降到 0.857** —— 说明 v1 的「完美第二层」也**部分受益于**命名线索。

**方法学教训（应写入论文的方法章节）**：
> **在一个候选集里，标签名如果与任务结构相关，就等于把答案的一部分交给了模型。** 任何用「语义化标签名」做的分类评测，都必须报告一次**不透明键对照**，否则测的是命名而非判断。
> 本项目的两个最大数据集恰恰**没有**这个线索（MASSIVE 的 `alarm_set` / CLINC150 的短意图名都不是自描述分类法），因此 **v1 的结论本会朝错误方向误导设计**。

## 3. 采纳的结论（v2 为准）

### 3.1 单层高基数不可用（P1 + P6b 双重确认）

- P1：N=20/21 准确率 **0.00**，AUC 衰减到 **0.47**；
- P6b：N=21 扁平准确率 **0.333**。

→ **把 MASSIVE（60 意图）或 CLINC150（150 意图）直接单层喂给 `choice` 会落在已实测的完全失效区。**

### 3.2 分层分解**可行**，且逐层准确率站得住

- **coarse（6 选项）= 0.762**；
- **fine 在 coarse 正确条件下 = 0.857**；
- **端到端 = 0.667**，**是扁平 0.333 的两倍**。

→ **每层都落在 P1 认定的可用区（≤10 选项）内**，且**层间复合的代价（0.762 × 0.857 = 0.653 ≈ 实测 0.667）与独立假设吻合**，说明**没有额外的层间交互损伤**。

### 3.3 但对 MASSIVE/CLINC150 的具体含义：**两层不够**

| 数据集 | 类数 | 若每层 ≤6–10 选项，所需层数 |
|---|---|---|
| MASSIVE | **60** | ≥2 层（6×10 或 8×8） |
| CLINC150 | **150** | **≥3 层**（例如 6×5×5） |

**用 0.667/层的两层复合率外推**：
- 2 层（每层 0.667 端到端）→ **CLINC150 需 3 层**；
- **3 层预估端到端 ≈ 0.667 × 0.857 ≈ 0.57**（第二层之后再乘一次层准确率）——**这已经接近多层分解的收益边界**，必须实测，不能外推。

→ **裁定：MASSIVE 可用两层；CLINC150 需要三层，且第三层的实测是 MASSIVE/CLINC150 能否进入主分析的先决条件。**

### 3.4 一处意外且有价值的观察：**coarse 的错误语义分散**

v2 的 coarse 混淆（5 个错误）：
```
access   → hardware
software → shipping
shipping → hardware
account  → money
```
**不是集中在某个吸引子，而是散落在语义上无关的组**（v1 则是全部倒向 software）。
→ **不透明键移除了语义线索，也移除了错误的相关结构** → 这对论文**有利**：**错误更接近独立**，因此分层设计**不会因系统性偏见而整体失效**。

## 4. 限制（必须随结果报告）

1. **探测电池，不是研究电池**：21 条 authored ticket，**每格 1 次调用**，单一配置。
2. **分类法是自撰的，不是 MASSIVE/CLINC150 的真实分类法**；层数与组大小分布仅近似。
3. **v1 与 v2 用的是同一批条目与同一分类法**，差异**仅来自键名与组描述**——这使反转归因干净，但也意味着**样本量不足以给出精确准确率**。
4. **未测**：三层复合、组大小不等的影响、真实 MASSIVE/CLINC150 标签名（其命名风格与 v1/v2 均不同）。
5. 本机 **cuda（RTX 5060 Laptop, sm_120）**；未测 CPU。
