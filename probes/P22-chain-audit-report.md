# P22 — CHAIN-AUDIT：上限被打破，互补性**仍然不存在**（架构主张就此结案）

> 实测：2026-09-22 · **96 条多跳链式核验**（K∈{2,4,8,16} × 24）· 真值由程序模拟 · LLM 与 Laya 配对
> 原始数据：`results\P22-chain-audit.json` · 复现：`src\items\p22_chain_audit.py`
> 生成成本 **零**（纯 Python），模型调用成本约 **3 美分**

---

## 1. 为什么必须做这个电池

互补性主张一直**无法判定**，因为此前每个电池上 LLM 都**触顶**（权威定位 48/48；校准 1100/1100）。**当一方不失败时，无法测量「两者是否失败在不同处」。**

**换条目无用**——现有条目全是「模板匹配 + 单跳核验」，与 LLM 的强项完全重合。**必须换结构。**

**CHAIN-AUDIT 的结构**：审计轨迹含 K 个操作行（`+d / −d / ×2 / ÷2`），其中一部分标记 **`SUPERSEDED — DO NOT APPLY`**，问题要求**最后一条未被作废步骤之后的值**。

三个使其对模型变难的属性：
1. **多跳**：需携带中间值通过 K 步，一次失误即终局；
2. **必须注意到「缺席」**：`SUPERSEDED` 行**必须跳过** —— 正是本论文中心假说所指向的同一根轴；
3. **数值精度**：加倍放大误差。

**证书**（复用 P5 机制）：生成器**断言** `simulate(seed, steps) ≠ simulate(seed, steps, 忽略作废行)`，故 `SUPERSEDED` 标记**是承重的而非装饰的**；不满足者**在构建期即被拒绝**。

## 2. 结果：**上限被打破**

| 链长 K | n | **LLM 准确率** | **Laya 准确率** | 随机（4 选项） |
|---|---|---|---|---|
| 2 | 12 | **0.833** | 0.417 | 0.25 |
| 4 | 12 | **1.000** | 0.250 | 0.25 |
| 8 | 21 | **0.429** | 0.286 | 0.25 |
| 16 | 24 | **0.417** | 0.250 | 0.25 |
| **合计** | **69** | **0.5942** | **0.2899** | 0.25 |

→ **LLM 总体 0.594 < 0.95 → 上限解除**，互补性**首次可测**。✅

**LLM 的深度曲线**：0.833 → **1.000** → 0.429 → 0.417。
→ **先升后降**：K=2 时略显吃力（0.833），K=4 满分，**K≥8 起崩塌到约 0.42**。
→ 这是本项目**唯一一条随深度下降的能力曲线**，且**与 horizon 概念同构**。

**LLM 的失效结构**：**14.5%** 的条目它选了「忽略 `SUPERSEDED`」的那个答案 → **它确实在「必须注意到某行被作废」这件事上失败**，正是中心假说预期的位置。

## 3. 结果：互补性**仍然不存在**

| 指标 | 值 |
|---|---|
| n（配对） | **69** |
| LLM 准确率 | 0.5942 |
| Laya 准确率 | 0.2899 |
| 混淆矩阵 | 皆对 **12** / **仅 Laya 对 8** / 仅 LLM 对 **29** / 皆错 20 |
| **观测一致率** | 0.4638 |
| **随机一致率** | 0.4604 |
| **κ** | **0.0062** |
| `P(Laya 对 \| LLM 错)`（n=28） | **0.2857** |
| `P(Laya 对 \| LLM 对)`（n=41） | **0.2927** |
| **Δ_catch** | **−0.0070** |

**三条读法**：

1. **κ = 0.006** —— 两个判定器的一致性**与随机无异**。它们**确实失败在不同处**。
2. **但 Δ_catch = −0.007** —— **Laya 在 LLM 失败处并不更可靠**。它那 8 次成功**分散在两侧**（LLM 失败处 8 次、LLM 成功处 12 次，按各自基数折算后比率几乎相同）。
3. **因此：两者独立失败 ≠ 互补。** 一个判定器的错误与另一个**不相关**，**并不能让它成为有用的备份**；**互补性要求的是「条件优势」，不是「独立性」。**

### 3.1 这是对架构主张的**结案**

**预声明判读**（写于运行前）：
> 「若上限破除但 Δ_catch 不 > +0.10 → 即使在 LLM 失败处，类型化判定器也不覆盖其错误。」

**实测 Δ_catch = −0.007** → **判定：主张不成立。**

**且这次不能再以「上限效应」辩解**——**上限已经破除，LLM 确实在失败（41%），而廉价判定器仍不提供覆盖率。**

**裁定：架构主张放弃。** 论文退守为**测量与刻画**（§7.5 的备选退路），**并如实报告这是一个被证伪的假设，而非未完成的探索。**

## 4. 一个附带的重要对照：**两种根本不同的失效模式**

| | LLM | Laya |
|---|---|---|
| K=2 | 0.833 | 0.417 |
| K=4 | 1.000 | 0.250 |
| K=8 | 0.429 | 0.286 |
| K=16 | 0.417 | 0.250 |
| **形状** | **随深度崩塌** | **平坦，恒在随机附近（0.25–0.29）** |

→ **Laya 的准确率在 K=2 时就只有 0.417**，而 K=2 是本电池里**最简单**的形态（两次运算、多为零到一次作废行）。
→ **它在最浅的链上就已接近随机，且随深度不再变化** → **它不是在「随深度退化」，而是根本没有在执行链式计算。**
→ 这与 P19 的发现一致：**它在「需要注意到某物缺席」的任务上塌缩**，而本电池**每一行都在要求它注意 `SUPERSEDED` 标记**。

**两种失效模式的对照**，是本节对论文主线的独立贡献：

| 判定器 | 失效方式 | 是否随负载恶化 |
|---|---|---|
| **LLM** | **误差复合**：能力随链长崩塌 | ✅ 是 |
| **Laya** | **能力缺位**：恒定在随机附近 | ❌ 否 |

→ **对「长线任务」的含义**：**LLM 的失效是累积性的、可随深度预测的；Laya 的失效是恒定的、与深度无关。**
→ **因此用一个恒定失效的组件去「兜底」一个累积失效的组件，在原理上不可能奏效** —— 这正是 Δ_catch ≈ 0 的结构性原因。

## 5. 限制

1. **K=2 与 K=4 各只有 n=12**（生成器因「作废行不承重」而丢弃了部分条目）→ 该两格的准确率**精度低**；
2. **单次采样**、LLM 为非思考模式、单一模型配置；
3. **Laya 在 K=2 的 0.417 可能是「部分执行」而非随机** —— n=12 下 5/12 与随机 3/12 的差异**不显著**，故本报告只说「接近随机」，不说「等于随机」；
4. **`SUPERSEDED` 是显式标记** —— 若换成需要推断的「软作废」，结果可能不同；**未测**；
5. **本电池仍非长线任务** —— 它是**单次调用内的多跳**，不是**跨会话的累积**。**horizon 实验仍未执行**（§10.1 第 1 项）。
