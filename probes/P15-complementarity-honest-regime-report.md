# P15 — 部署情形下的互补性：**不存在，且我自己的假设被推翻**

> 实测：2026-09-22 · **40 条真实 Banking77 测试集语句** · Laya 走完整层级 vs LLM 扁平 77 类
> 原始数据：`results\P15-complementarity-strong-regime.json` · 复现：`src\items\p15_complementarity_strong_regime.py`

---

## 0. 先说两个我自己的错误

**错误一（本轮发现并修复）**：`parse_label` 返回**选项键**（`k52`），而 `truth` 是**意图名**（`transfer_timing`）。两者比较**永远不可能相等**，报出 LLM **0.0** 准确率。
→ **它是被「0.0 低于 1.3% 的随机率」这个不可能值暴露的。** 修正为「先把键解析回选项文本再比较」后，真实值为 **0.75**。
→ **这是本项目第三次同类错误**：标签空间不匹配把「关于模型的结论」变成了「关于 harness 的结论」。前两次是散文解析器（P14）与位置偏差（P2）。

**错误二（假设层面，本轮被数据推翻）**：我在 P14 后判断「互补性必须在 Laya 的相对强项区制上测」，并认定 **P7 第二层的 0.867 是它的强项区制**。
**这个假设是错的**，原因见 §2——**那 0.867 是条件于「祖先正确」测出的，不是部署数字。**

## 1. 结果（部署情形）

| 配置 | 准确率 |
|---|---|
| **LLM 扁平 77 类** | **0.750** |
| **Laya 完整层级**（自选组 → 组内选意图） | **0.225** |
| Laya 的**组选择**准确率 | **0.275** |
| 随机（77 类） | 0.013 |

**混淆矩阵（40 个配对条目）**：

| | 计数 |
|---|---|
| 两者都对 | 7 |
| **仅 LLM 对** | **23** |
| **仅 Laya 对** | **2** |
| 两者都错 | 8 |

| 指标 | 值 |
|---|---|
| `P(Laya 对 \| LLM 错)` | **0.200** |
| `P(Laya 对 \| LLM 对)` | **0.233** |
| **Δ_catch** | **−0.033** |
| **κ** | **0.020** |

→ **Δ_catch 为负**：Laya 在 LLM 做错时答对的概率，**低于** LLM 做对时它答对的概率。
→ **κ ≈ 0.02**：两者的一致性**与随机无异**。
→ **「仅 Laya 对」只有 2 条**，而「仅 LLM 对」有 23 条——**23 : 2**。

**我脚本自动生成的 verdict 写的是「COMPLEMENTARITY EXISTS」，这是错的**——它只检查了 `typed_only_correct > 0`，而没有看 `Δ_catch` 的**符号**。**Δ_catch 为负时不存在互补性**，无论「仅 Laya 对」是否非零。该判据已修正。

## 2. 我推翻的假设（这是本轮最重要的认知更正）

**P7 的 0.867 不是 Laya 的「强项」，而是「条件化产物」。**

P7 测的是「**已知正确祖先组**的前提下，在 ≤3 个候选里选」。真实部署里**祖先不知道自己错**——Laya 先选组，**组选择只有 0.275**，一错就终结。

| 层级 | 准确率 |
|---|---|
| 组选择（10 组） | **0.275**（随机 0.10） |
| 组内选择（≤3，条件于祖先正确） | 0.867（随机 0.333） |
| **端到端** | **0.225** |

→ **0.867 是一个不该被引用的数字**，除了作为「层内技能」的说明。**部署准确率是 0.225。**
→ 而且 **0.225 甚至低于单层扁平的表现**——**层级对 Laya 是净损失**，因为组选择引入的错误（72.5%）远大于它换来的候选集缩小收益。

**另一个反直觉点**：我原以为「扁平 77 类」会严重伤害 LLM（选项列表约 2,451 字符）。**实测 LLM 扁平 77 类拿 0.75**，反而**远好于**走层级的 Laya。
→ **层级设计对 LLM 是不必要的**，对 Laya 是有害的。

## 3. 架构主张的裁决

**在测过的两个区制里，互补性都不存在**：

| 区制 | Laya | LLM | 仅 Laya 对 | 仅 LLM 对 | Δ_catch | 出处 |
|---|---|---|---|---|---|---|
| 权威定位（模板匹配） | 0.458 | **1.00** | **0** | 26 | 未定义（LLM 无错） | P14 |
| 77 类意图分类 | 0.225 | **0.750** | **2** | **23** | **−0.033** | P15 |

→ **「廉价异种判定器做第一层、不确定时升级」这一架构，在本项目测过的两个任务类别上都得不到支持。**
→ LLM 在两个区制上都**远强**，且在其中一个上**更强到零错误**。
→ **架构主张应当放弃**，论文退守为**测量与刻画**论文（这一直是 D2/V5 给的备选退路，且中心主张不依赖它）。

**必须写进局限性**：互补性**只测了两个区制**，且都是「有明确标签、可由单一短文本判定」的任务。**开放式、需要多跳检索、或标签空间极大且需要外部知识**的任务未测，那里的结论可能不同。**不得把「两个区制上无互补」外推为「任何情况下都无互补」。**

## 5. 限制

1. **n=40**，一项动 0.025。**Δ_catch = −0.033 在 n=40 下不显著**；能说的是**「没有证据支持互补」**，不能说是「证明了无互补」。
2. **污染**：Banking77 是 Laya 的先前集合。**但注意方向**——污染若存在，**对 Laya 有利**，而实测 Laya 仍大幅落后，故该结论**在保守方向上成立**。
3. **LLM 0.75 不是天花板**：说明本电池对 LLM **有区分度**（不同于 P14 的 1.00），这是好事；但 0.25 的错误率中**有多少来自 77 选项的提示词负担、多少来自真实能力，未拆分**。
4. **Laya 的层级用程序化分组**（P7 的 token 相似度凝聚），**顶层分组质量本身已被 P7 判为瓶颈**（组选择 0.275）。**换一个语义上更好的分组可能改善 Laya 的端到端**，本轮未测。
5. **只测了一个 LLM 配置**（`deepseek-flash`、非思考模式、单次采样）。
