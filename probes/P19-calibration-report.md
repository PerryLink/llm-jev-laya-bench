# P19 — 校准曲线（1100 条，程序化真值）：**Laya 比常数预测器更差**

> 实测：2026-09-22 · **1100 条二值项**（5 难度 × 220）· 真值**由构造计算**，无人工标注、无模型标注
> 原始数据：`results\P19-calibration.json` · 复现：`src\items\p19_calibration.py`
> **两个判定器在同一条目上配对运行**，故 ECE 比较是条目内的。

---

## 1. 头条：Laya 的 Brier **不如一个常数预测器**

| | Laya | LLM |
|---|---|---|
| **准确率** | **0.5673** | **1.0000** |
| **ECE** | **0.2259** | **0.0028** |
| **Brier** | **0.2571** | **0.0000** |
| 常数预测器 Brier（按基率 0.4） | **0.240** | 0.240 |
| **是否优于常数预测器** | ❌ **否（更差）** | ✅ 是 |
| n | 1100 | 1100 |

→ **Laya 的 Brier 0.2571 高于「永远预测基率 0.4」的 0.240。**
→ 这**正是 V3 指出的校准缺陷 (b)**：**纯 ECE 排行榜会奖励一个零分辨率的判定器**。因此本文**同时报告 Brier 与常数基线**，而不只报 ECE。
→ 但注意：**Laya 的 ECE（0.226）并不显得灾难性**——因为它**偏向不足自信与过度自信两侧**，误差部分相互抵消。**只看 ECE 会低估问题。**

## 3. **最重要的单条结果：`no_support` —— Laya 把「没有陈述」当作支持**

设计 `no_support` 的**唯一目的**，就是检验 R12 写进协议的那条规则：

> 「某物只有在 STATE 真的说了它时才被支持。**没有陈述不构成对它的证据。**」

| 判定器 | `no_support` 准确率 | 平均声称 P(true) | 真值 |
|---|---|---|---|
| **Laya** | **0.3091** | **0.5643** | 全部 FALSE |
| LLM | **1.0000** | 0.0012 | 全部 FALSE |

→ **面对「候选值根本没出现」的条目，Laya 平均给出 P(true) = 0.564，即倾向于断言该值就是当前值**，准确率仅 0.309。
→ **它把「没有陈述」读成了对主张的支持。**
→ 这是一个**可复现、有 n=220 支撑**的失效模式，且**直接违背该判定器被设计用于的合规/核验类任务的基本前提**。

**与截断发现的关系**：两者同源——**Laya 的失效都发生在「必须注意到某物是否存在」的场合**。截断是**没注意到输入被截掉**；`no_support` 是**没注意到证据不存在**。

## 4. 逐难度分解（Laya）

| 难度 | n | 准确率 | 平均声称 P(true) | 真值 |
|---|---|---|---|---|
| `explicit_support` | 220 | **0.9909** | 0.7811 | TRUE |
| `partial_support` | 220 | 0.6818 | 0.5881 | TRUE |
| `partial_contra` | 220 | 0.5818 | 0.4922 | FALSE |
| **`explicit_contra`** | 220 | **0.2727** | **0.6070** | FALSE |
| **`no_support`** | 220 | **0.3091** | **0.5643** | FALSE |

**两个反直觉点**：

1. **`explicit_contra`（0.273）比 `partial_contra`（0.582）更差。** 当 state **明确声明了另一个值为当前值**时，Laya **更容易**把候选值判成当前值——**它似乎在找「候选值出现过」这个事实，而不是「它是当前值」这个结论**。
2. **`explicit_support` 近乎完美（0.991）**，与 `explicit_contra` 的 0.273 形成**极端不对称**。
→ **这解释了为什么本项目早期的简单条目上 Laya 拿 1.00**（P8 的 40 项全部是「state 明确陈述答案」）——**那正是它唯一擅长的形态**。

## 5. LLM 一侧：完美，且因此**上限**

| 难度 | n | 准确率 | 平均 P(true) |
|---|---|---|---|
| 全部 5 档 | 各 220 | **1.0000** | 与真值一致（TRUE 档 ≈0.998，FALSE 档 ≈0.004）|

- **ECE 0.0028**，**Brier 0.0000**（四舍五入后），**只有两个箱有质量**（0.0–0.1 有 660 条、0.9–1.0 有 440 条）——**它从不给出中间概率**。
- **含义**：本语料对 LLM **没有区分度**。它是**校准的**，但**校准到两个极端**，因此在**中段没有任何校准信息可测**。
- **不得据此宣称「LLM 普遍优于 Laya」**：本语料是模板化的核验任务，且 LLM 在该形态上**触顶**。

## 6. 对论文的直接贡献

**Result C 现在从定性变成定量**：

| 原状态 | 现状态 |
|---|---|
| 「confidence 与正确性解耦」（若干生动个案） | **n=1100 的可靠性曲线**；中段差距 −0.21…−0.31；**Brier 劣于常数预测器** |
| 「confidence 不能用作门控」 | **定量支撑**：0.4–0.8 区间的声称概率**系统性高出实测 21–31 个百分点** |
| 缺 `no_support` 这类对照 | **n=220**：Laya 平均 P(true)=0.564，**把没有陈述读成支持** |

**新增一条协议强制项**（由 §1 直接推出）：
> **校准报告必须同时给出 Brier 与「常数预测器基线」。** 只报 ECE 会**低估**一个两侧误差相互抵消的判定器的问题。

## 7. 限制

1. **语料是模板化的**（5 个模板 × 常量池）。**绝对准确率不是能力估计**；可用的是**校准形状**与**难度间的相对差异**。
2. **每个判定器每条目一次采样**，故无采样方差估计；类型化判定器确定性（R13 实测逐位相同），LLM 非思考模式温度默认。
3. **LLM 触顶**（1.0000/1100）→ 本语料对它的**校准曲线只有两个箱**，中段无信息。
4. **`no_support` 的措辞有解释空间**：状态里确实有「ledger extract / successive revisions」等脚手架文字。**严格说它测的是「候选值不出现时是否倾向于否定」**，而非「对纯空状态的判断」。
5. **单机、单设备、单一时段**；未测多语或 `typed-decisions` checkpoint。
