## 0. 论文定位（经三轮修订后的最终版）

**原设想**：证明「判定模型比 LLM 更便宜/更准」，并提出混合架构。
**实测裁决**：
- ❌ 「更便宜」不成立为**卖点**（钱根本不是约束，见 §3.1）；
- ❌ 「更准」不成立（Laya 在部署情形下 0.225–0.458，LLM 0.75–1.00）；
- ❌ 「混合架构有收益」**两个区制上都不成立**（P14/P15）。

**最终定位：测量与刻画论文。**

> **标题（暂）**：*当判定器的自报字段说谎：三个判定层在相同条目上的代价、延迟与失效边界*

**四条主张，三条独立成立**：

| # | 主张 | 状态 |
|---|---|---|
| ① | **成本不是约束**；真正的约束是**延迟**与**状态窗口** | ✅ 三方实测 |
| ② | **仪器的自报字段不可信**——五种独立失效，全部在真实调用中复现 | ✅ 五条证据 |
| ③ | **判定器能力随时间/语义负载塌缩，而置信度不随之变化** | ✅ 完整曲线 |
| ④ | 跨物种判定器提供**增量覆盖** | ❌ **负结果**（两区制均否） |

**第 ④ 条转为负结果报告**，这本身有价值：既有的级联文献（FrugalGPT / RouteLLM / AutoMix / learning-to-defer）**全是同族**（LLM 判 LLM），本文提供**异种对照**，结论是「**异种并不自动意味着互补**」。

## 2. 结果 A：成本不是约束（全部实测）

| 判定器 | 单次成本（USD） | 延迟 | 备注 |
|---|---|---|---|
| **LLM**（`deepseek-flash`，非思考模式，结构化判定） | **$0.0000484** | p50 **671 ms**，max 1,008 ms | n=48 |
| **Jev**（openrouter，`typesafe/jev-1.13-20260917`） | **$0.0000142 – $0.0000991** | p50 **1,380 ms**，**max 11,984 ms** | n=13 |
| **Laya**（本地 cuda） | **≈ $0**（自托管算力） | **37.4 ms**（批 1） | n=30 |

**核心论证**：设计里 120 个检查点/运行。**最贵的 LLM 也只有 $0.0000484/次** → 全运行约 **$0.006**。
→ **钱不是约束。** 而**延迟跨三个数量级**（37 ms / 671 ms / 1,380 ms），**且方向有利于本地判定器**。

**必须同时报告的两个限定**：
1. **峰谷价差 2×**（R2：低谷为高峰一半），故成本须标注时段；
2. LLM 成本对**推理 token**敏感（V3 实测 reasoning token 计入输出价）→「非思考模式」这一配置**必须写明**，否则成本可差一个数量级。

**Jev 延迟的诚实限定**：p50 1,380 ms 与 R13 测得的**未认证 403 拒绝往返**（1,011–2,349 ms）**同量级** → 延迟**由传输主导**，换网络位置即变。**不得写成判定器的固有属性。**

## 3. 结果 B：仪器的自报字段不可信（五条独立证据）

| # | 现象 | 实测 | 出处 |
|---|---|---|---|
| 1 | **mock 产生可信的结果表** | 14 项校准电池得出合理置信度分布，但 **Brier 0.359**，比常数 0.5（0.25）更差 | R12 |
| 2 | **`truncated` 双向皆错** | english **滞后 111 字符**（静默）；multilingual **提前 4,773 字符误报**；三者标志都在 3,193 字符触发而真实钳位差 2× | P3 |
| 3 | **`fits: true` 配已截断的输入** | 决定性证据（置于尾部）被丢弃、答案翻错，而 `fits:true`、无 `truncated`、无 warning | R13/P3 |
| 4 | **`probability` 会反号一半条目** | live 实测 `answer:"false", noul:0.02, probability:0.98`；且**同一响应里 `band` 朝向 true、`probability` 朝向所选**，方向相反 | P12/P13 |
| 5 | **`conflicted`/`undecided` 实战不可达** | 8 次 `check`，`sufficient` **全部 ≤0.14**，解析器需 ≥~0.5 → **五值词表实际退化为三值**；**证据真正冲突时系统报「证据不足」** | P13 |
| 6 | **窗口是「启动配置」的属性，而非模型或代码的属性** | 同一钉定修订上：载 **1** 个 checkpoint → 钳位 **1024**；载 **≥2** 个 → 钳位 **512**（各重启 3 次，确定复现）。**代码不是变量，loadout 才是** | P16–P18 |

**第 1 条的意义**：**一个没有判断能力的判定器，可以产生完全可信的结果表。** 这是全文最强的方法论论点。

**第 6 条的意义（本轮新增，且是对论文表述的硬约束）**：
> **「Laya 的窗口是 512 token」是不完整的表述，对另一个操作者可能错 2 倍。** 必须写成「在载入 N 个 checkpoint 的 loadout 下」。
> 本项目**所有** Laya 测量都在**三 checkpoint loadout** 下取得 → **512 窗口与 111 字符未告警区间对它们一致适用**，且已在**钉定修订**上复现（P17：onset 3,082 / `truncated` @3,193 / 钳位 512，与 P3 逐项吻合）。
> **机制未隔离**：论文只报告经验规律，**不得声称**「第二个 checkpoint 为何砍半窗口」的原因。
> **一条可用结论**：只载入 english 一个 checkpoint 可把可用窗口**从 512 翻倍到 1024 token**，代价是失去多语与 typed-decisions。

**版本归属状态（目标项 4 已关闭）**：Result B 的截断数字**现已归属到钉定修订**，不确定性来源从「代码修订」更正为「启动配置」，而后者对全部测量是**一致的**。

**各自的应对（协议强制项）**：
- 判别 live/mock **一律用 `provider == "mock"`**，不靠 warning 缺失（短路调用会返回**没有 warning** 的响应）；
- **绝不用 `truncated`/`fits` 门控**，一律自算 tokenizer；
- 记录 **`noul`** 作为 P(true)，**永不记录 `probability`**；
- 每个 state 报告**同义改写差值**，>0.05 的 state 不得用于阈值决策。

## 4. 结果 C：能力塌缩与 confidence 解耦

### 4.1 判定器能力画像（全部 n≥20，且经去相关选项顺序验证）

| 任务类型 | 判定器 | 准确率 | n | 出处 |
|---|---|---|---|---|
| state **明确陈述**答案 | LLM | **1.00** | 48 | P14 |
| state **明确陈述**答案 | Laya | **1.00** | 40 | P8 |
| 权威定位（多处陈述中找权威来源） | LLM | **1.00** | 48 | P14 |
| 权威定位 | Laya | **0.458** | 48 | P9b |
| 77 类意图分类（扁平） | LLM | **0.750** | 40 | P15 |
| 77 类意图分类（扁平） | Laya | **0.033** | 30 | P7 |
| 意图分类（Laya 完整层级，部署情形） | Laya | **0.225** | 40 | P15 |
| 20 候选相关性判断 | Laya | **0.00** | 18 | P1 |

**注意**：**Laya 的 0.867（P7 第二层）不得作为能力数字引用**——它是**条件于祖先正确**的层内技能；部署情形是 **0.225**（P15）。

### 4.2 confidence 与正确性解耦 —— **现有 n=1100 的定量曲线**

**主结果（P19，1100 条二值项，真值由构造计算，两判定器配对运行）**：

| | Laya | LLM |
|---|---|---|
| 准确率 | **0.5673** | **1.0000** |
| **ECE** | **0.2259** | **0.0028** |
| **Brier** | **0.2571** | **0.0000** |
| 常数预测器 Brier（基率 0.4） | **0.240** | 0.240 |
| **优于常数预测器？** | ❌ **更差** | ✅ |

→ **Laya 的 Brier 高于「永远预测基率」** → 它是**负信息量**的预测器。
→ **但它的 ECE（0.226）并不显得灾难性**，因为两侧误差相互抵消 → **新增协议条款：校准必须同时报 Brier 与常数基线，只报 ECE 会低估问题。**

**可靠性曲线形状**（Laya，10 箱，全部有质量）：**中段严重过度自信**——位于 0.4–0.8 的三个箱，实测频率比声称概率低 **21–31 个百分点**；两端反而尚可。

**最强单条结果 —— `no_support`（n=220）**：
> 面对「候选值根本没出现在 state 里」的条目，**Laya 平均给出 P(true) = 0.564**（倾向断言该值即当前值），准确率仅 **0.309**；LLM 为 **1.0000 / P(true)=0.0012**。
> → **它把「没有陈述」读成了对主张的支持**，直接违背该判定器用于合规核验的基本前提。

**另一处严重不对称**：`explicit_support` **0.991** vs `explicit_contra` **0.273**。
→ 当 state **明确声明另一个值才是当前值**时，Laya 反而**更容易**把候选值判为当前值——**它在找「候选值出现过」，而不是「它是当前值」**。
→ **这解释了本项目早期简单条目上 Laya 拿 1.00 的原因**：那正是它唯一擅长的形态。

**逐个案证据（保留，作为曲线上的点）**：

| 观测 | 值 | 出处 |
|---|---|---|
| Laya 全探测**最高** confidence | **0.9981——出现在唯一的错答上** | R13 |
| Laya 纯噪声 state | `noul 0.0011 / confidence 0.9989` | R13 |
| Laya 正确但 confidence 低 | 0.2543、0.3337 | R13 |
| Laya 同一 p、不同 framing | confidence **0.5399 vs 0.0046**（差 117×） | R13 |
| Laya 去载体（全错）平均 confidence | **0.218（高于带载体全错时的 0.178）** | P9b |
| **LLM 同批条目** | 全部 ≈1.0 且**全部正确** | P14 |

→ **对照价值**：**同一批条目上，一个判定器的满置信度是对的，另一个的满置信度是错的。** 用户无法从返回的 confidence 区分。

### 4.3 高基数下 confidence 反向指示正确性

Laya 出厂温度 `choice:11+ = 0.1006`（等价 logits ×10）→ 恰在选项最多、选项文本被压缩到无法区分的那一档，模型被配置成最自信。
实测：20 选项时正确选项获 **p = 0.0000** 而 confidence **1.0000**（P1，18 次中 4 次）。

## 5. 结果 D：跨物种互补性（**负结果**）

| 区制 | Laya | LLM | 仅 Laya 对 | 仅 LLM 对 | Δ_catch | n |
|---|---|---|---|---|---|---|
| 权威定位（模板匹配） | 0.458 | **1.00** | **0** | 26 | 未定义（LLM 零错） | 48 |
| 77 类意图分类 | 0.225 | **0.750** | **2** | **23** | **−0.033** | 40 |

→ **两个区制上都不存在互补性。** Δ_catch 在可计算的那次为**负**，κ ≈ 0.02（与随机无异）。
→ **架构主张放弃。**

**必须写的局限性**：只测了两个区制，都是「有明确标签、可由单一短文本判定」的任务。**不得外推为「任何情况下都无互补」。**

## 6. 方法学贡献（独立于上述结果）

1. **证书机制**：条目须通过「带载体可推导 **且** 去载体不可推导」两臂检验。**它在开发过程中四次否定作者自己的条目设计。**
2. **去相关选项顺序是强制项**：同一批条目，顺序去相关把 Laya 从 **0.125 抬到 0.625**（位置偏好被误读为能力）。
3. **不透明选项键是强制项**：描述性键名给了扁平臂免费归组线索，**把结论方向整个反转**（v1 得「分层更差」，v2 得「分层好一倍」）。
4. **n<20 的分类格不可作结论**：本会话四次由小格高分得出错误结论（P1 N=2、P5c、P9、P5b T4）。
5. **结构输出优势可由解析器缺陷伪造**：散文臂一度测出 0.50，实为抽取器 bug；修正后 0.958。
6. **标签空间不匹配会伪造结论**：`parse_label` 返回键、`truth` 是名字，报出 LLM 0.0（低于随机率）——**被不可能值暴露**。
